**包名**：`@cordis-tavern/ct-client-web`

**功能**：前端声明发现、`window.boot` 排序与惰性加载控制。三块职责：

- **前端声明发现**：扫描所有插件的 `ct.client` 声明，构建前端插件列表并排序
- **`window.boot` 管理**：控制插件加载顺序，支持立即加载与延迟加载
- **惰性加载控制**：注册惰性加载模块、按需加载、预加载

**它要消费的前端契约（未定案）**：`ct.client` 的 `platform` / `inject` / `immediately`、前端产物入口 `dist/client/index.js` ——
目前**都没有读取方、都没有定案**，见 [[项目文档/开发文档/待办|待办]]。
