# 插件概念总览

状态：🟡 初步设计（Web 主链 **0.1.0-rc.1** 起；ui-slots **0.1.1-alpha.1** / ui-layout **0.2.1-alpha.1** / ui-theme **0.2.0-rc.1** / event-scope **0.1.2-alpha.1**；persist / log-router **0.0.1-alpha.2**；版本以各包 `package.json` 为准）

> **插件不在内核仓库**：它们是独立 npm 包，由 pnpm 装进 `$CT_HOME` 的 node_modules，实现落在 **`cordis-tavern-plugin`** 插件仓库。
> 每个插件自己的设计在自己的文件夹里（见下表）；本页只写共性的东西与索引。

## 插件是什么

- 一个**模块化的 npm 包**：身份与入口用 npm 标准字段声明，npm 表达不了的语义用 `ct` 扩展字段 —— `ct` 是**扩展，不是替代**。
- 它的产物**不在 cordis-tavern 仓库内**：该仓库的 `pnpm-workspace.yaml` 的 `packages` 只匹配 `vendor/*`。
- 包名正典：**`@cordis-tavern/ct-*`**（详见 [[项目文档/项目设计文档/插件设计/插件契约层|插件契约层]] 的「包命名」）。

## 与内核的对接约定（通用）

| 约定 | 要求 |
|---|---|
| 装载 | 包名写进环境级 `ct.profile`；包目录须位于 `$CT_HOME/profile/<env>/node_modules/` 或 `$CT_HOME/node_modules/` |
| bundle | `package.json` 的 `ct.bundle.path` 指向包内 `cordis.patch.yml`，其 `insert[]` 声明服务 id 与要装载的包名 |
| 服务 | 通过 `ctx.provide()` / `inject` 暴露与声明能力；**加载顺序由依赖关系决定** |
| client factory | **`{ name, apply }`**；无 `apply` 的身份 stub 会被装载器跳过（warn） |
| **前端产物入口** | **`exports["./client"]`（正典）**；有 `ct.client.platform: "web"` 必须声明 |
| 发布 | `pnpm pack` / `pnpm publish`；Web 主链 **`0.1.0-rc.1`** 起（ui-slots 0.1.1-alpha.1、ui-layout 0.2.1-alpha.1、ui-theme 0.2.0-rc.1、event-scope 0.1.2-alpha.1），persist/log-router **`0.0.1-alpha.2`**，宿主 **`0.1.2-rc.2`** |

> 契约细节只写在 [[项目文档/项目设计文档/插件设计/插件契约层|插件契约层]]；
> 未交付与未定案项在 [[项目文档/开发文档/待办|待办]]。
