主要目的是完成[[cordis-tavern项目设计]]中的骨架开发，和部分基础插件开发。对应 [[cordis-tavern总览]] 中的第一阶段——"总体开发"。

## 本次开发目标

1. **搭建项目基础架构**：完成 monorepo 工程结构、vendor 依赖本地化、构建工具链配置，使项目能够完整启动运行。
2. **实现启动层与构建工具**：完成应用启动与插件构建。插件注册与拓扑排序由 `@cordisjs/plugin-loader` 负责，不另建注册表。
3. **完成基础插件开发**：实现首批可运行的插件（以独立 npm 包形式），验证插件契约层（`package.json` 声明解析、插件加载流程）的正确性。
4. **打通前后端链路**：实现基础的 Web 前端承载，确保项目可通过浏览器访问并识别一个 client 插件。

## 开发边界

### 在范围内

- 项目工程化：monorepo 搭建、TypeScript 配置、pnpm workspace、vendor 依赖管理
- 启动层与自定义构建工具（不含插件注册表/环境表——拓扑排序由 `@cordisjs/plugin-loader` 负责）
- 插件契约层的声明规范定义与解析实现（参考 [[项目文档/项目文档/cordis-tavern项目设计/插件契约层|插件契约层]]）
- 首批基础插件：host、client-web、frontend-static、logRouter（以**独立 npm 包**形式提供，不在仓库内）
- 基础的插件加载与生命周期管理

### 不在范围内

- AI 对话功能（LLM 传输适配器、Chat 后端调度器等）
- 角色卡、世界书、Prompt 蓝图等业务域功能
- 语音、图像生成等沉浸式体验功能
- 移动端适配
- Agent 功能
- 插件市场的完整生态
