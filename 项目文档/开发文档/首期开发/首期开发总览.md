主要目的是完成[[cordis-tavern项目设计]]中的骨架开发，和部分基础插件开发。对应 [[cordis-tavern总览]] 中的第一阶段——"总体开发"。

## 本次开发目标

1. **搭建项目基础架构**：完成 monorepo 工程结构、vendor 依赖本地化、构建工具链配置，使项目能够完整启动运行。
2. **实现核心基建层**：完成启动层、自定义构建工具、插件注册表/环境表等非插件内核模块。
3. **完成基础插件开发**：实现首批可运行的插件，验证插件契约层（`package.json` 声明解析、插件加载流程）的正确性。
4. **打通前后端链路**：实现基础的 Web 前端承载与后端通信，确保项目可通过浏览器访问并呈现基础 UI。

## 开发边界

### 在范围内

- 项目工程化：monorepo 搭建、TypeScript 配置、pnpm workspace、vendor 依赖管理
- 核心基建层全部模块（参考 [[cordis-tavern项目设计#核心基建层]]）
- 插件契约层的声明规范定义与解析实现（参考 [[cordis-tavern项目设计#插件契约层]]）

- 基础的插件加载与生命周期管理

### 不在范围内

- AI 对话功能（LLM 传输适配器、Chat 后端调度器等）
- 角色卡、世界书、Prompt 蓝图等业务域功能
- 语音、图像生成等沉浸式体验功能
- 移动端适配
- Agent 功能
- 插件市场的完整生态

## 基础插件开发计划

首期需要完成以下基础插件的开发，确保项目骨架可运行：

### 插件总览

| 插件              | 职责                                    | 开发  |
| --------------- | ------------------------------------- | --- |
| host            | 提供注册路由的服务                             | 待开发 |
| client-web      | 负责插件的前端声明发现和windows.boot的排序，以及惰性加载的控制 | 待开发 |
| frontend-static | 静态前端资源托管与服务，承接host无法匹配的路由             | 待开发 |
| logRouter       | 日志路由与输出管理                             | 待开发 |

### 插件详细说明

#### host

- 职责：提供注册路由的服务
- 关键设计：作为 HTTP 服务的宿主，提供路由注册接口，允许其他插件注册路由处理函数

#### client-web

- 职责：负责插件的前端声明发现和 `window.boot` 的排序，以及惰性加载的控制
- 关键设计：扫描插件的前端声明（`ct.client`），构建加载顺序，控制预加载与惰性加载的执行时机

#### frontend-static

- 职责：静态前端资源托管与服务，承接 host 无法匹配的路由
- 关键设计：作为 fallback 路由处理器，当 host 的路由表中没有匹配项时，尝试从静态资源目录中加载文件

#### logRouter

- 职责：日志路由与输出管理
- 关键设计：提供日志分级（info/warn/error）、路由到不同输出目标（控制台、文件等）的能力

## 里程碑

### M1: 工程搭建

- **交付物**：monorepo 项目结构、vendor 依赖本地化、pnpm workspace 配置、TypeScript 基础配置
- **验收标准**：`pnpm install` 成功，项目目录结构符合规划

### M2: 构建工具

- **交付物**：自定义构建工具（基于 esbuild 封装）、构建脚本、开发/生产构建流程
- **验收标准**：`pnpm build` 成功，能够正确打包插件代码

### M3: 核心基建

- **交付物**：启动层（IoC 容器）、插件注册表/环境表、插件生命周期管理
- **验收标准**：应用可启动，插件可注册并按顺序加载

### M4: 插件契约

- **交付物**：`package.json` 声明解析（`ct.bundle`、`ct.client`、`ct.commands`）、插件发现机制
- **验收标准**：插件可通过声明被发现，前端插件声明可被正确解析

### M5: 基础插件 - host

- **交付物**：host 插件，提供 HTTP 服务和路由注册能力
- **验收标准**：host 可启动 HTTP 服务，其他插件可注册路由

### M6: 基础插件 - client-web

- **交付物**：client-web 插件，前端声明发现、`window.boot` 排序、惰性加载控制
- **验收标准**：前端插件可按声明顺序加载，惰性加载机制正常工作

### M7: 基础插件 - frontend-static

- **交付物**：frontend-static 插件，静态资源托管与 fallback 路由
- **验收标准**：可访问静态前端页面，host 无法匹配的路由能正确降级

### M8: 基础插件 - logRouter

- **交付物**：logRouter 插件，日志分级与路由输出
- **验收标准**：日志可按级别输出到不同目标（控制台、文件等）
