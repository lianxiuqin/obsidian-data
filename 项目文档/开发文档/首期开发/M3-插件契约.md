# M3: 插件契约

## 目标

实现 `package.json` 中 `ct` 字段的解析，完成插件声明发现机制。

详细设计参见 → [[项目文档/项目文档/cordis-tavern项目设计/插件契约层|插件契约层]]

## 目录结构

```
cordis-tavern/
├── contract/
│   ├── package.json
│   ├── src/
│   │   ├── index.ts
│   │   ├── parser.ts
│   │   ├── types.ts
│   │   └── validators/
│   │       ├── bundle.ts
│   │       ├── client.ts
│   │       └── commands.ts
│   └── tsconfig.json
└── ...
```

> 路径为占位，待内核模块的最终位置定案后同步。
> 插件源码**不在仓库内**：插件是 npm 包，由 pnpm 安装到 `$CT_HOME/node_modules/`。

## 声明格式定义

### ct.bundle

声明插件 bundle 描述文件（`cordis.patch.yml`）的路径。

### ct.client

声明插件的前端结构，包括 platform（平台）、inject（依赖插件）、immediately（是否预加载）、external（外部包依赖）。

### ct.commands

声明插件提供的命令，包括 command（命令名）、path（入口路径）、explain（说明）、subcommands（子命令组）。

## 解析器设计

### parser.ts

提供声明解析器，支持解析单个插件声明、批量解析和声明格式校验。定义 PluginContract 接口，包含 name、bundle、client、commands 字段。

## 验收标准

- [ ] 可正确解析 `ct.bundle` 字段
- [ ] 可正确解析 `ct.client` 字段
- [ ] 可正确解析 `ct.commands` 字段
- [ ] 可发现所有已声明的插件
