# 参考架构
[[sillytavern]]是一个**本地安装、开源、专为“高级用户”打造的 LLM 前端界面**。它并非提供模型本身，而是作为一个功能极其强大的“控制中枢”，让你能精细地驾驭各类 AI 模型，进行深度角色扮演、故事创作和互动对话。
[[cordis]]是一个元框架（Meta Framework）—— 即“用于构建框架的框架”。它不耦合任何具体业务领域，只专注于解决一个核心问题：如何让软件的各个组件可以安全地组合、解绑与重组。
# 重构目的
为了大幅增强sillytavern的拓展能力，并通过内置插件包对sillytavern的原功能进行实现
